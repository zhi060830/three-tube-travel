# Three.js 隧道穿越 Demo
基于 Three.js 实现管道隧道穿梭动画，前端面试3D项目案例。

## 在线预览
https://zhi060830.github.io/three-tube-travel/

## 操作说明
按下 **键盘 ↑ ↓ 方向键** 控制镜头前进/后退，体验隧道穿越效果。

## 技术栈
- Three.js（CDN方式引入，无需本地node_modules）
- WebGL 3D渲染
- 纹理贴图、自定义管道几何体
- 原生ES Module开发
